# UI各部の名称・役割一覧（UIコンポーネントガイド）

本アプリケーションで使用されている各UIパーツの名称、画面上の位置、および役割をまとめたガイドです。コード上のコンポーネント名や関連する処理も記載しています。

---

## 1. 画面レイアウトと主要パーツ一覧

### 1-1. ウィンドウタイトルバー (Title Bar)
* **画面上の位置**: 画面の一番上（最上部）
* **役割**:
  * アプリケーション名（「📄 AIチャットノート制作」）を表示します。
  * `drag-area` に指定されており、この領域をドラッグすることでウィンドウ全体を移動できます。
  * 右上の領域は、OS標準のウィンドウ操作ボタン（最小化・最大化・閉じる）のためのスペースになっています。
* **コード上の表記**: `<div className="drag-area ...">` (最上部)

### 1-2. リボンバー (Ribbon Bar)
* **画面上の位置**: 画面の左端（縦長の細い帯）
* **役割**:
  * アプリ全体の表示ビューを切り替えるメインナビゲーションです。
  * **ノートアイコン**: ノートの閲覧・編集画面（デフォルト）に戻ります。
  * **グラフアイコン**: ノート同士の繋がりを可視化するグラフビューに切り替えます。
  * **Git同期アイコン**: ノートフォルダをGit/GitHubにプッシュ・同期します（同期中はローディングアニメーションになります）。
  * **歯車アイコン**: 設定画面（Gemini APIキーや保存フォルダの設定）をポップアップ表示します。
* **コード上の表記**: `<nav className="flex w-12 flex-col ...">` / `RibbonButton`

### 1-3. サイドバー / ノートリスト (Sidebar / Notes List)
* **画面上の位置**: リボンバーのすぐ右側（左カラム）
* **役割**:
  * **「＋ AIノート作成」ボタン**: クリックするとノート名を指定してAIによる文章自動生成プロセスを開始し、下書きを自動作成します。
  * **「＋ 新規ノート作成」ボタン**: AIを起動させず、空のテンプレートで即座に新しいノートを手動作成します。
  * **検索窓**: 入力したキーワードでノート一覧を瞬時に絞り込み（フィルタリング）します。
  * **ノート一覧リスト**: 保存されているMarkdownノート（`.md`ファイル）を一覧表示します。クリックするとそのノートが中央のエディタで開かれます。
* **コード上の表記**: `<aside className="flex w-64 ...">` / `filteredNotes`

### 1-4. タブバー (Tab Bar)
* **画面上の位置**: エディタ領域の上部
* **役割**:
  * 現在開いているノートをタブ形式で横並び表示します。
  * ドラッグ＆ドロップでタブの順番を入れ替えることができます。
  * タブ内の「X」ボタンを押すと、そのノートのタブを閉じます。
* **コード上の表記**: `SortableTab` / `<DndContext>` / `openTabs`

### 1-5. エディタツールバー (Editor Toolbar)
* **画面上の位置**: タブバーのすぐ下、エディタの上部
* **役割**:
  * **編集/プレビュー切り替えボタン (Eye / Edit3アイコン)**: エディタ（生テキスト編集）とMarkdownプレビュー（装飾された読みやすい表示）を切り替えます。
  * **保存ボタン (Save / Checkアイコン)**: 現在のノートを手動で保存します。自動保存も行われますが、手動で即座に保存したい場合に使用します。
  * **削除ボタン (Trash2アイコン)**: 現在開いているノートファイルをローカルディスクから削除します。
* **コード上の表記**: `<div className="flex h-10 items-center justify-between ...">`

### 1-6. エディタ本体 (Editor / Markdown Preview)
* **画面上の位置**: 画面の中央部分（メインエリア）
* **役割**:
  * **編集モード時**: Markdownの生テキストを記述するテキスト入力エリア（`textarea`）が表示されます。
  * **プレビューモード時**: MarkdownがHTMLとして美しくレンダリングされ、Wikiリンク（`[[リンク名]]`）やコードブロック、コールアウト、テーブルなどがデザインされた状態で表示されます。
* **コード上の表記**: `editMode === 'edit'` の条件分岐部分

### 1-7. 下部チャットエリア (Bottom Chat Area)
* **画面上の位置**: 中央エディタ領域の最下部（固定表示）
* **役割**:
  * **AIストリーミング回答表示カード**: AIが生成中のときのみ出現し、リアルタイムで生成される回答テキスト（`streamedText`）が流れるように表示されます。
  * **設定ドロップダウン (3つ)**:
    1. **チャットモード（Chat Mode）**: 「思考整理（deep-think）」「ノート作成（markdown-struct）」「長文詳細説明（long-explain）」を選択します。
    2. **AIスピード（AI Speed）**: 「高速（fast）」「思考（thinking：長考モデル用）」を選択します。
    3. **AIモデル（AI Model）**: 「Lite」「Flash」「3.5」を選択します。
  * **チャット入力テキストボックス**: AIへのプロンプトを入力します。Shift+Enterで改行、Enter単体で送信します。
  * **送信ボタン**: メッセージをGemini APIに送信します。
* **コード上の表記**: `{selectedNote && ( <div className="border-t ..."> )}`

## 2. 状態・ダイアログ・右クリックメニューの名称

### 2-1. 新規ノートモーダル (New Note Modal)
* 新規作成ボタンを押したときに画面中央に表示されるダイアログ。入力された名前でノートを作成します。（AIノート作成の場合は作成後に自動執筆を行います）

### 2-2. 設定ダイアログ (Settings Overlay)
* リボンバーの歯車アイコンを押したときに表示されるダイアログ。Gemini APIキー、ノートの保存ディレクトリパス、GitHubのリモートURL、Git自動同期チェックボックスなどを設定します。

### 2-3. ノートリストの右クリックメニュー (Context Menu)
* サイドバーのノートを右クリック（コンテキストクリック）した際にカーソル位置にポップアップ表示される独自のフローティングメニュー。
  * **名前変更 (Rename)**: ノート名を入力してファイル名のリネーム（変更）を行います。
  * **削除 (Delete)**: ノートファイルをローカルディスクから直接削除します。
* **コード上の表記**: `contextMenu` / `renameNote`
